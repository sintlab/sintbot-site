SLACK · CLAUDE CODE / CODEX

在 Slack 派活，在 Mac 上完成

在 Slack 私聊里发任务，或在频道中 @ 机器人。SintBot 调用你 Mac 上的 Claude Code 或 Codex，在绑定的项目目录工作，再将结果回复到会话；频道任务在对应线程回复。

macOSClaude Code / Codex更新于 2026-11-17

开始之前

准备一台保持唤醒的 Mac，以及已安装并完成账号配置的 Claude Code 或 Codex。桌面 App 自带 Node.js；完整下载和首次启动步骤见安装指南。

SLACK · 私聊与频道

把项目接入 Slack

在 Mac 上选好项目，用已经填好的链接创建你自己的 Slack 应用，粘贴两枚令牌，再给机器人发一句话。SintBot 通过 Socket Mode 连接，不需要公网地址，免费工作区也能用。

  1. 01创建应用
  2. 02两枚令牌
  3. 03发一句话
  4. 04第一条任务
开始之前

先在 Mac 上装好并登录 Codex 或 Claude Code。你需要有在 Slack 工作区安装应用的权限；工作区要求管理员审批时，可以自己新建一个免费工作区。一个 Slack 应用只给一台 Mac 用。

01 在接入页创建应用

首次打开会进入接入页。填项目名、选执行器，在「聊天平台」里选「Slack」，点「在 Slack 创建应用」：Slack 打开时，应用的权限和事件已经填好。选择工作区，点 Next，再点 Create。按钮下面的「声明为 Slack Agent」一般保持不勾：勾上后频道线程里会多出 Slack 原生的停止（Stop）按钮和「Working…」状态，但工作区访客不能再使用这个应用，和它的私信也都会变成线程，这两点以后都撤销不了。

↗

02 粘贴两枚令牌

  1. 在 Slack 里应用的 Basic Information 页，往下找到 App-Level Tokens，点 Generate Token and Scopes，权限选 connections:write 并生成。把 xapp- 开头的令牌粘贴到接入页，页面会立即验证。Slack 的应用设置页第一次打开可能要等十几秒，一直空白就刷新一次。
  2. 在接入页点「打开安装页」，在 Slack 里点 Install to 加工作区名的按钮（例如 Install to Acme），再点 Allow（中文界面是「允许」）。
  3. 复制 xoxb- 开头的 Bot User OAuth Token，粘贴后点「连接 Slack」。

两枚令牌只保存在这台 Mac，不要发到聊天里。贴错了框，页面会告诉你贴的是哪一种令牌。

这台 Mac 要经代理才能访问 Slack 时（例如中国大陆网络），在 Slack 步骤的「代理」里填 http:// 开头的地址；打开接入页的终端里设置了代理时，这里会自动填上。代理会随连接一起保存，后台服务和桌面 App 以后启动时也走它。它是整个服务的网络代理，其他聊天平台和本机的模型工具也会走它。主机要写 IP 地址或英文域名，中文域名不收。

03 给机器人发一句话

接入页显示「等待你的消息…」时，点「在 Slack 里打开机器人」，在 10 分钟内给它发任意一句话。想用频道：先用 /invite @机器人名 把它请进频道，再在频道里 @它。

↗

SintBot 把这个会话绑定到项目，机器人回复「已连接项目 …」，接入页随后打开控制台。

04 发第一条任务

在同一个会话里，先发一条只读请求：

发给 Slack 里的机器人（频道里要 @它）

读取这个项目 README.md 的第一行，只回复这一行。不要改任何文件。

把回复和 Mac 上文件的第一行对照。任务进行中，你的消息上会有 ⏳，答案送达后变成 ✅。要停止任务，发 !stop（频道里要 @机器人）。接着看在 Slack 里工作。

已经在用飞书、企业微信或本机对话？添加 Slack

打开控制台「设置 → Slack」，选项目目录和执行器，按同样的三步操作，再给机器人发一句话。现有连接、本机对话和项目都保留。

↗

接入后，卡片显示工作区、连接状态和已绑定的项目数。展开「高级」可以刷新连接状态，或打开 Slack 里的应用设置。

再绑一个频道

先用 /invite @机器人名 把机器人请进频道，再到控制台「群 · 项目 → 配置群项目」里选这个频道，并选目录和执行器。这里只列出机器人已加入的频道；手填的频道 ID 若机器人还不在里面，控制台会提示先邀请它。一个应用可以服务多个项目，但只连接一台 SintBot。

链接打不开？

手动创建应用：到 api.slack.com/apps 选择 Create New App → From a manifest，选工作区并粘贴清单文件，然后从第 02 步继续。不要打开令牌轮换：它是单向开关，打开后关不掉。

发了消息没有回复？

在频道里要 @机器人，并确认已经把它请进频道；提示机器人还不在频道里时，在那个频道里发 /invite @机器人名，重装应用后也要重新邀请。到「设置 → Slack」看连接状态：显示连接中断时检查网络或代理；显示连接失败说明令牌已被撤销或应用已被移除（最多约 5 分钟后显示），需要用新令牌重新接入。这台 Mac 要经代理才能访问 Slack 时（例如中国大陆网络），在接入页 Slack 步骤的「代理」里填上地址再试；已经在用的安装，在配置文件里设置 proxy（如 {"https": "http://127.0.0.1:7890"}）后重启服务。确认没有另一台 SintBot 在用同一个应用：Slack 把每条消息只交给应用的其中一条连接。控制台发现可能有另一台机器在用这个应用时，Slack 连接会标黄提示。接入时超过 10 分钟没发消息，在接入页点「重试」。

验证第一条真实任务

完成绑定后，再发一条独立任务：

读取项目 README 的第一行，只回复这一行。

把回复与本机文件核对，确认平台、项目目录和执行器都连通。接着可要求“查看 Git 状态并总结，不修改文件”，再尝试一次明确、可回退的小修改。

日常使用与当前范围

私聊直接发消息；频道里需 @ 机器人，跟进时在原线程再次 @。命令使用 !help、!status、!stop；/sint 也可在频道中使用。保持 Mac 唤醒，关闭 App 窗口不会停止后台服务。

当前 Slack 显示状态与最终回复，不提供任务进度文字，也不能把生成的文件直接回传到 Slack。答案会给出本机项目中的文件路径。每个 Slack 应用只连接一台 SintBot。
