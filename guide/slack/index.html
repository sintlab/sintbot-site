SLACK · CLAUDE CODE / CODEX

Slack messages. Local project work.

Send a task in a Slack DM or @mention the bot in a channel. SintBot runs Claude Code or Codex in the project folder on your Mac and sends the answer back. A channel reply stays in the task’s thread.

macOSClaude Code / CodexUpdated November 17, 2026

Before you start

Use a Mac that stays awake, with Claude Code or Codex installed and its account configured. The desktop app includes Node.js. Follow the download and first-launch steps before connecting a chat platform.

SLACK · DIRECT MESSAGES AND CHANNELS

Connect your project to Slack

Choose a project on your Mac, create your own Slack app from a link that is already filled in, paste two tokens, then send the bot one message. SintBot connects over Socket Mode, so you need no public address, and a free workspace works.

Before you start

Have Codex or Claude Code working on your Mac. You need permission to install apps in the Slack workspace; if yours needs admin approval, create a free workspace of your own. One Slack app serves one Mac.

01 Create the app from the setup page

First launch opens setup. Enter a project name, choose the executor and pick “Slack” under Chat platform. Select “Create app in Slack”: Slack opens with the app’s permissions and events already filled in. Pick your workspace, select Next, then Create. Leave “Declare it as a Slack Agent”, below the button, unticked unless you want Slack’s own Stop button and “Working…” status in channel threads: a declared app cannot be used by workspace guests, every direct message with it becomes a thread, and neither can be undone.

↗

02 Paste the two tokens

  1. On the app’s Basic Information page in Slack, scroll to App-Level Tokens, select Generate Token and Scopes, add the connections:write scope and generate. Paste the token that starts with xapp- into setup; it is checked at once. The app settings page in Slack can take ten seconds or more to load the first time; reload it if it stays blank.
  2. Select “Open install page” in setup, then in Slack select the install button named after your workspace (for example Install to Acme), and Allow.
  3. Copy the Bot User OAuth Token that starts with xoxb-, paste it and select “Connect Slack”.

Both tokens are saved on this Mac only; never post them in a chat. If a token lands in the wrong field, setup says which kind you pasted.

If this Mac reaches Slack only through a proxy (for example on mainland-China networks), enter an http:// address under “Proxy” in the Slack step; it is filled in for you when the terminal that opened setup has a proxy set. The proxy is saved with the connection, so the background service and the desktop app use it later. It is the network proxy of the whole service, so other chat platforms and the local model tools use it too. The host must be an IP address or a host name in plain ASCII.

03 Send the bot one message

When setup shows “Waiting for your message…”, select “Open the bot in Slack” and send it any message within 10 minutes. To use a channel instead, invite the bot with /invite @your-bot-name and @mention it there.

↗

SintBot binds that conversation to the project, the bot replies “已连接项目 …” (project connected) and setup opens the console.

04 Send your first task

In the same conversation, start with a read-only request:

Send to the bot in Slack (@mention it in a channel)

Read the first line of this project’s README.md and reply with only that line. Do not change any files.

Check the reply against the first line of the file on your Mac. While the task runs your message shows ⏳; it becomes ✅ when the answer arrives. To stop a task, send !stop (@mention the bot in a channel). Then continue with working in Slack.

Already using Feishu, WeCom or local chat? Add Slack

Open Settings in the console and expand the Slack card (platform cards start collapsed), choose the project folder and executor, then follow the same three steps and send the bot one message. Your existing connections, local chat and projects are kept.

↗

Once connected, the card shows a status dot, the workspace and the number of bound conversations even when collapsed. Expand it, then Advanced, to refresh the connection status or open the app’s settings in Slack.

Bind another channel

Invite the bot to the channel with /invite @your-bot-name, then pick that channel under Groups · Projects → Add a group project in the console and choose its folder and executor. Only channels the bot has joined are listed; if you type in the ID of a channel it has not joined, the console tells you to invite it first. One app can serve several projects but connects to only one SintBot.

The link does not open?

Create the app by hand: at api.slack.com/apps choose Create New App → From a manifest, pick the workspace and paste the manifest file, then continue from step 02. Leave token rotation off: it cannot be turned off again.

No reply to your message?

In a channel, @mention the bot and check it was invited; when SintBot says the bot is not in the channel, send /invite @your-bot-name there, and invite it again after reinstalling the app. Check the connection status under Settings → Slack: if it shows Disconnected, check the network or proxy; if it shows a failed connection, a token was revoked or the app was removed (shown within about 5 minutes), so connect again with new tokens. If this Mac reaches Slack only through a proxy, enter it under “Proxy” in the Slack step of setup and try again; for an installation already in use, set proxy in the configuration file (for example {"https": "http://127.0.0.1:7890"}) and restart the service. Make sure no other SintBot uses the same app: Slack hands each message to only one of an app’s connections. If another machine seems to be using it, the Slack connection in the console turns yellow with a warning. If more than 10 minutes passed during setup without a message, select Retry on the setup page.

Verify your first real task

After the connection is bound, send a separate task:

Read the first line of the project README and reply with only that line.

Compare the answer with the file on your Mac. Then try “Summarize the Git status without changing any files” before requesting a small, reversible edit. This verifies the platform, project folder and coding agent together.

Everyday use and current limits

Send ordinary messages in a DM. In a channel, @mention the bot; for a follow-up, @mention it again in the original thread. Use !help, !status or !stop; /sint also works outside threads. Keep the Mac awake. Closing the app window leaves its background service running.

The current Slack integration shows status and final replies, not running progress text. It cannot send generated files back into Slack; answers name their paths in the local project. Connect each Slack app to only one SintBot instance.
